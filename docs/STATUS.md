# SP500 Heatmap — состояние проекта

> Рабочая заметка. Из GitHub Pages исключена (`docs/_config.yml`).

Обновлено: 11.11.2026

## Что это
Приложение для iPhone (SwiftUI): тепловая карта компаний S&P 500 по секторам, подсекторам
и компаниям, с переключателем периода (сегодня, 1, 3, 7, 30, 180 дней, год).
- App Store: id 6813677835, опубликована версия **1.0.1 (2)** (вышла 25.10.2026), только iPhone.
- App Store Connect: https://appstoreconnect.apple.com/apps/6813677835/distribution
- Дело в ПДУ: 8.10 «SP500» (App); 14.19 «SP500 — кнопки в Chrome».

## Откуда берутся данные
1. **История цен закрытия** — Yahoo (yfinance), скрипт `fetch_history.py` → файл `history.db`.
   Обновляет GitHub Action `.github/workflows/refresh-history.yml` и коммитит базу в репозиторий:
   - 22:00 UTC пн–пт (на деле стартует около 01:00–03:00 UTC);
   - 04:00, 07:00 и 10:00 UTC вт–сб — утренние проходы (GitHub запускает их с опозданием на несколько часов).
     Ночью Yahoo часто отдаёт за только что закрытую сессию последнюю сделку вместо окончательного закрытия
     (04.11.2026: MSFT 517.01 вместо 520.99). Утренний проход перезаписывает эти цены окончательными.
2. **Сервер** (`server.py`, FastAPI) сам скачивает `history.db` из GitHub при старте и раз в час.
   По нему считает % за периоды (`/api/v1/performance`).
3. **Живые цены** — Finnhub WebSocket, только в обычные часы торгов 9:30–16:00 по Нью-Йорку.
   Отдаются приложению через `/ws` раз в секунду.
   Когда в истории появляется закрытие дня, сервер показывает его вместо последней живой цены (с 04.11.2026).
4. **Список компаний и капитализация** — `SP500_with_market_cap.csv` (от 16.09.2026).
   Компании, у которых нет новых цен дольше 7 дней (ушли с биржи), на карту не попадают (с 04.11.2026).

## Серверы
- **Рабочий** (его использует 1.0.1): https://217-160-93-254.sslip.io/sp500 (WebSocket `/sp500/ws`).
  Служба `sp500-api` на сервере проектов; код — git clone этого репозитория, ключ Finnhub — в env-файле на сервере.
  Точные пути и вход — в памяти Claude (sp500-heatmap-app), не в публичном репозитории.
- **Старый** на Render: https://sp500-heatmap-api.onrender.com — для тех, кто ещё на версии 1.0.
  Пуш в main автоматически пересобирает его. Выключать — только после решения владельца.
- Проверка свежести данных: `/health` → `history_through`; в Пульте ботов страница «SP500: данные».

## Как выложить правку сервера
1. Правка и тесты: `python3 -m pytest -q tests`.
2. Коммит и `git push` (Render пересоберётся сам).
3. Рабочий сервер: в папке кода от имени служебного пользователя `git checkout -- history.db`,
   затем `git pull --ff-only` и перезапуск службы `sp500-api` (команда — в памяти Claude).
   `history.db` на сервере перезаписывается автоскачиванием, поэтому перед pull его сбрасываем.
4. Проверить `/health` и карту.

## Как выпустить версию приложения
- Номер версии и адреса сервера (`BASE_URL`, `WEBSOCKET_URL`) — в `SP500Heatmap/SP500Heatmap.xcodeproj/project.pbxproj`.
- Сборка 1.0.1: archive без подписи → exportArchive с профилем «SP500Heatmap AppStore» → загрузка altool.
- **На проверку в App Store — только после последнего «да» владельца на вопрос «Отправлять?».**
- Снимки экрана для App Store — в `appstore/`, их делает UI-тест.

## Известные проблемы (04.11.2026)
- 11.11.2026 GitHub запустил утренний проход (10:00 UTC) в 17:42 UTC, во время торгов, и Yahoo отдал текущие цены как «закрытие» 11.11 (AAPL 354.33). Сервер показывал их вместо живых, а % за периоды считал по незакрытому дню. Исправлено: `fetch_history.py` не пишет сегодняшнюю сессию до 16:30 по Нью-Йорку и удаляет такие строки, если они уже есть (коммит ca419c9).
- 05.11.2026 ночной проход (запущен GitHub в 02:01 UTC) снова взял предварительные цены за 04.11 (AAPL 353.18 вместо 349.51), а утренние проходы GitHub к 10:00 UTC ещё не запустил — ПДУ показал «расхождений в ценах: 4». Исправлено ручным запуском Action и перезапуском `sp500-api`. Расписание GitHub ненадёжно: опоздания до 7 часов.
- Связь с Finnhub часто рвётся: за торги 03.11 — 48 переподключений и 18 отказов «HTTP 429».
  Из-за этого днём часть живых цен замирает. Вероятная причина — тот же ключ Finnhub
  у старого сервера на Render (не проверено).
- Журнал службы пишется пачками (вывод Python буферизуется), время в нём неточное.
- Список компаний от 16.09.2026: новые участники индекса на карте не появятся, пока не обновить `SP500_with_market_cap.csv`.
- Адрес sslip.io зависит от IP сервера: смена IP сломает приложение до нового выпуска.
- Папки `trading_system/` (заготовка «сигналы до открытия рынка», к приложению не относится) и `build/` не в git — ждут решения владельца.
